# NICU Prototype

AI-assisted neonatal intensive care workflow prototype.

## Overview

This project explores how AI can support neonatal intensive care unit (NICU) workflows through clinical summarization, monitoring assistance, and healthcare-oriented interface design.

The goal is to provide an open-source foundation for healthcare AI experimentation and research workflows.

## Features

- Clinical monitoring prototype
- AI-assisted summarization
- Healthcare workflow interface
- Research-oriented architecture

## Tech Stack

- Python
- FastAPI
- React
- PostgreSQL
- LLM integration
